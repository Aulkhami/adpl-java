# Module 5 - Prinsip SOLID Part 1
## Panduan Pengerjaan Laporan Praktikum

Untuk laporan praktikum module 5, kalian ditugaskan untuk merefaktor beberapa class di dalam project ini supaya sesuai dengan prinsip SOLID.

### S: Single Responsibility Principle (SRP)

Refaktor `services/UserService.java` mengikuti SRP. Disarankan membuat file baru untuk setiap kelas baru.

### O: Open-Closed Principle (OCP)

Refaktor `calculator/AreaCalculator.java` mengikuti OCP.

### L: Liskov Substitution Principle (LSP)

Refaktor `birds/Chicken.java` mengikuti LSP.

## Kriteria Isi Laporan
- Lampiran kode _bad practice_ yang belum direfaktor (kode apa adanya dari repository ini).
- Lampiran kode setelah di-refaktor menggunakan prinsip SOLID.
