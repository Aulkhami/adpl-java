# Cara Memakai Repository Ini

#### 1. Clone repository ke local, atau download secara manual. (klik tombol Code warna hijau di kanan atas)
<img width="943" height="356" alt="image" src="https://github.com/user-attachments/assets/1a5cafd5-7267-48f8-9be5-d5168ca89b12" />

2. Setiap module merupakan satu project Java Maven sendiri yang bisa dibuka dengan NetBeans.
3. Baca README.md di masing-masing folder module untuk panduan lebih spesifik per modul. Direkomendasikan untuk membaca file README.md di website GitHub ini langsung supaya lebih mudah dibaca (kecuali kalau punya .md reader/editor sendiri).
<img width="928" height="154" alt="image" src="https://github.com/user-attachments/assets/619958f9-a938-4866-9794-246409524358" />

4. Happy coding! Stay determined...
